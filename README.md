# 🇪🇸 태양의 나라, 스페인 — 두 가족 여행 2027

2027.9.10(금) – 9.19(일) · 어른 4 + 중3 딸 2, 총 6명의 마드리드·세비야·바르셀로나 스페인 여행 가이드 웹페이지입니다.

일정안은 **세비야 코스(p7s)** 하나이고, 상단 세비야 코스 옆 **✈️ 항공일정** 버튼에서 인천 ⇄ 스페인 오픈조 9박·8박 TOP 10 후보를 볼 수 있습니다. 항공일정은 자동으로 조회하지 않고, 직접 조사한 표를 Claude에게 주면 갱신합니다(아래 '항공일정 업데이트' 참고).

👉 **보기: https://hs-code97.github.io/spain/**

## 구성
- `index.html` / `style.css` / `app.js` — 모바일용 가이드 페이지
- `data.js` — **일정·장소·메뉴 데이터** (내용 수정은 이 파일만 고치면 됩니다)
- `flights.js` — **항공일정 후보 데이터** (`FLIGHT_META`, `FLIGHTS`)

## 자주 고칠 부분
- 숙소 상세 주소나 위치 확정 시 `data.js` → `PLACES`의 `stay_madrid`, `stay_sevilla`, `stay_granada`, `stay_bcn`의 `lat`, `lng`, `q` 수정
- 일정 시간 및 세부 동선 변경은 `DAYS` 배열의 `time`, `title`, `text` 수정 (세비야 3일은 `PLANS` 안 `p7s`의 `s4`·`s5`·`s6`)
- 쇼핑 목록 및 준비물 체크리스트는 `DONKI`(쇼핑 미션), `PACKING`(준비물) 배열 수정

## 항공일정 업데이트 (수동)
직접 조사한 표를 Claude에게 붙여 넣고 "항공일정 업데이트해줘"라고 하면, Claude가 `flights.js`를 다시 쓰고 `index.html`의 `flights.js?v=`를 올려 푸시합니다.

표에 넣을 것 (한 줄 = 항공편 조합 하나):
- 박수(8박/9박), 순위, 출·귀국일(요일), 패턴(A = 마드리드 IN·바르셀로나 OUT / B = 바르셀로나 IN·마드리드 OUT)
- 출국편: 항공사, 출발·도착 시각(+1 여부), 경유지·대기시간(직항이면 '직항')
- 귀국편: 같은 항목, 인천 도착 날짜·시각
- 1인 요금 또는 성인 3인 합계(세금 포함, 둘 중 하나만 있어도 됨), 조사 사이트
- 선택: 위탁 수하물 메모, 특이사항(예: 이스탄불 경유)

표 형식은 자유입니다(엑셀 복사, 스크린샷, 메모 모두 가능). 비어 있는 항목은 Claude가 묻거나 '확인 필요'로 표시합니다. 조사 날짜와 사이트는 화면 상단 '🔄 조회' 줄에 표시됩니다.
